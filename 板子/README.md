## 快速开始

### 环境

- C++17（`-std=c++17`），GCC 9+ / MinGW-w64 均可
- 依赖 `#include <bits/stdc++.h>`，**非 GCC 环境（如 MSVC）不支持**
- `头.cpp` 与部分模板使用了 `__gnu_pbds`（`gp_hash_table` / `cc_hash_table` / `ordered_set`），同样需要 GNU 环境

### 编译运行

```bash
g++ -std=c++17 -O2 -o main 数学/ntt.cpp && ./main
```

### 使用方式

1. 新开一道题时，先复制 [`头.cpp`](头.cpp) 作为 `main` 骨架；
2. 按题目需要，把对应模板里的 `struct` / 函数整体粘贴进来（文件名后面标注 `片段` 的只提供函数本体）；
3. 注意各模板顶部的 `const int maxn` / `MAXB` / `N` 等上限要与数据范围匹配，这类常量按题目改是常态。

使用提示：

- `main` 默认按多组数据写（`cin >> t`），单组数据时把 `cin >> t` 注释掉并令 `t = 1`；
- `#define endl "\n"` 在**交互题**里必须注释掉，否则输出不会刷新；
- `mod` 默认 `998244353`，需要 `1e9+7` 时切换相邻的注释行；
- 位运算宏默认是 `*ll` 版本，操作 `int` 时记得换成 `__builtin_ctz` / `__builtin_clz` / `__builtin_popcount`；
- 不用 pbds 时删掉文件末尾的 `#include <bits/extc++.h>` 与 `__gnu_pbds` 段落，可明显加快编译。

## 使用约定

- **文件头自包含**：每个模板都自带 `#include`，单独 `g++ -c` 都能过；`片段` 类没有 `main`，要自己补。各模板自写的头部宏与 [`头.cpp`](头.cpp) 不完全一致，统一以 `头.cpp` 为准。
- **数组开在全局**：绝大多数模板用全局数组 + `maxn` 常量，粘进自己的代码时注意与其它模板的 `maxn` 重名。
- **模数**：默认 `998244353`，文件顶部的 `//const int mod = 1e9+7;` 就是切换开关。
- **目录里的非模板文件**：
  - `数据结构/BIT/.vscode/` 是本地调试配置，不影响模板；
  - `*.cph.*.prob` 是 VS Code cph 插件的测试数据缓存，可以随手删除或加进 `.gitignore`。
- **命名**：中文名直接对应算法内容，`（…）` 里一般是关键限制或做法；`·` 用来分隔同一模板的两个要点。
